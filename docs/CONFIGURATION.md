# Configuration

Copy `.env.example` to `.env` for local development. Existing environment variables take precedence. Restart the app after changes. Never commit `.env` or place keys in browser URLs.

## Core setup

| Setting | Purpose |
| --- | --- |
| `LLM_PROVIDER` | `groq` (example default), `anthropic`, or `openai`. |
| `GROQ_API_KEY` | Required only for live Groq analysis. Demo requires no key. |
| `GROQ_MODEL` | Example: `openai/gpt-oss-120b`; availability depends on the account. |
| `GROQ_FREE_TIER` | Sets displayed estimate to zero when true; does not enforce billing. |
| `LLM_TIMEOUT_SECONDS` | Provider request timeout; SDK retries can make total analysis time longer. |
| `LLM_REFLECTION` | False by default; true adds model-based reflection calls. |
| `PORT` | Public Streamlit port for `scripts/start_app.py`; defaults to 8501. |
| `API_BASE` | Backend URL for a separately started frontend; the combined launcher sets it automatically. |
| `AGENTIQ_API_TOKEN` | Internal API secret. Generated by the combined launcher if absent, forwarded by Streamlit, never entered by visitors. Set an identical value on both servers for separate deployments. |

## Other model providers

For Anthropic, select `LLM_PROVIDER=anthropic` and set `ANTHROPIC_API_KEY` plus `ANTHROPIC_MODEL`.

For an OpenAI-compatible endpoint, select `LLM_PROVIDER=openai` and set `OPENAI_API_KEY`, `OPENAI_MODEL`, and optionally `OPENAI_BASE_URL`. For OpenRouter, the supported configuration is:

```dotenv
LLM_PROVIDER=openai
OPENAI_API_KEY=your-openrouter-key
OPENAI_BASE_URL=https://openrouter.ai/api/v1
OPENAI_MODEL=openrouter/free
```

Provider selection alone does not establish model availability or answer quality. Check model IDs, account limits, and generated queries before a demonstration.

## Optional integrations

| Feature | Credentials | Enable flag | Supported behavior |
| --- | --- | --- | --- |
| Web search | `TAVILY_API_KEY` or `SERPAPI_KEY` | `ENABLE_WEB_SEARCH` | External lookup and benchmarks. |
| Weather | `OPENWEATHER_API_KEY` | `ENABLE_WEATHER` | City forecast for 1–5 days. |
| Finance | `ALPHAVANTAGE_API_KEY` | `ENABLE_FINANCE` | Stock quotes; other financial metrics are not implemented. |
| News | `NEWSAPI_KEY` | `ENABLE_NEWS` | Topic-based news search. Check your provider's deployed-app licensing. |
| Email | `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, optional `EMAIL_FROM` | `ENABLE_EMAIL` | Email a report when the user explicitly requests delivery. |

These tools are optional and disabled in the Render Blueprint. Set the enable flag to `true` after providing and verifying the relevant credential. The interface's feature list reflects configuration, not a live credential check. Email delivery has not been verified by this project's test runs.

## Data handling

Upload a UTF-8 CSV with a header row. Limits: 5 MB, 50,000 rows, and 100 columns. Uploaded data and history are shared on the deployment. Avoid confidential data in the public showcase. Live prompts and selected query results go to the model provider.

## Troubleshooting

- **App takes time to open:** a free Render service may need to wake from inactivity.
- **Live mode unavailable:** check the selected provider's key in the server environment.
- **Rate-limit response:** wait for provider quota to recover; demo mode uses no model quota.
- **Server credential mismatch:** separate frontend/API services must use the same internal token.
- **CSV cannot be used in demo:** switch to Live AI; demo analyses target the sample schema.
- **History disappears:** the hosting filesystem is temporary unless you configure persistent storage.
- **Tool failed:** inspect Execution evidence; the agent can recover, but not every failure produces a complete answer.

See [deployment](DEPLOYMENT.md) and [API reference](API.md).
